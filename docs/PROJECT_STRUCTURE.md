# Project structure

- `index.html` — semantic HTML page and content.
- `css/styles.css` — responsive styling, layout, typography, and accessibility states.
- `js/script.js` — mobile navigation, category filters, newsletter validation/demo feedback, and dynamic footer year.
- `README.md` — how to run the project and implementation notes.
- `docs/PROJECT_STRUCTURE.md` — this folder guide.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Important
Keep the CSS and JavaScript files in their folders so the relative links from `index.html` continue to work. For Android file-provider viewing, use the separate standalone HTML version supplied with the project ZIP.
